# Release Notes: v0.8.11-alpha-1

This release brings significant improvements to performance, authentication handling, and developer workflows, along with several UI enhancements.

## 🚀 Key Features & Improvements

### Authentication & Security
- **Auth Flow Rewrite:** Completely refactored the authentication system to rely on system-level Git credentials (GCM, SSH), removing the need for custom token storage (`keytar`) within the app. (f3ece8f)
- **Simplified Credentials:** Removed custom credential dialogs and management UI in favor of a smoother, system-integrated experience. (f3ece8f)

### Performance Optimization
- **Optimized Graph Rendering:**  Significantly improved performance of the commit graph and branches panel by implementing `React.memo` and optimizing re-render logic. (d9b4570)
- **Tag Loading Fix:** Fixed an issue where tag loading caused excessive Git processes and log spam. Tags are now fetched efficiently in a single batch. (d80fc91)
- **Reduced State Updates:** Implemented data comparison to prevent unnecessary UI updates during auto-refresh cycles. (d9b4570)

### UI Enhancements
- **Diff View Toggles:** Added a toggle for Split/Unified diff views in the file diff viewer. (785911f)
- **UI Polish:** Moved diff view toggle to a toolbar below the header for better accessibility. (0d73b9f)

## 🛠️ Infrastructure & CI/CD

- **Release Automation:** Added and refined a release script (`scripts/release-alpha.mjs`) to automate version bumping, tagging, and pushing. (f0df8df, 7066b00)
- **VirusTotal Integration:** Integrated VirusTotal scanning into the release workflow for enhanced security verification of artifacts. (8e11abd, 466c32d, 1e2a793)
- **Workflow Fixes:** Various improvements and fixes to GitHub Actions workflows, including artifact retention and cleanup. (466c32d, deef2de)

## 🐛 Bug Fixes

- **Tag Visibility:** Fixed an issue where annotated tags generated by the release script were not appearing in the commit graph. (d80fc91)
- **Script Fixes:** Resolved issues with release and VirusTotal scanning scripts. (41ead8c, b5b0647, ee8f3cb)
- **Cleanup:** Removed unused files and imports related to the legacy credential manager. (4a287e0)
