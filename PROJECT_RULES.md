# Project Rules

## Git Commit Policy

**Never commit changes without asking the user first.**

All git commits must be explicitly requested by the user. Do not automatically commit changes, even if they appear to be complete or ready.

### When to Commit

- Only commit when the user explicitly requests it (e.g., "commit this", "commit with message X", "check in")
- Wait for user confirmation before executing any `git commit` commands
- Always ask for a commit message if the user doesn't provide one

### When NOT to Commit

- Do not commit after completing a task automatically
- Do not commit as part of a multi-step process unless explicitly requested
- Do not commit "work in progress" or incomplete changes
- Do not commit on behalf of the user without explicit instruction
